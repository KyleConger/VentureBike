## Team goals (locked)

- Segments: **Mountain → Speed → Recreation**
- Digital **and** physical channels
- Maximize productive spend with emergency cash (Cash+CD ≥ $300k; Q1 CD = $0)
- Match top advertisements
- **1 new city each quarter** → all 4 open by Q4
- Compensation **above** industry average
- Strategy: high-margin segments · large geos · build/defend · lead · first to market · profit margin leader

## How we work each quarter

1. Export / paste new sim reports into `data/` / `Q1Data.xlsx`
2. Fill `quarters/QX/checklist.md`
3. Debate → lock choices in `quarters/QX/decisions.md` (majority vote)
4. Append `decisions/log.md`
5. Run pro forma from `templates/pro-forma.md`
