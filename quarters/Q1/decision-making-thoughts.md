## Second location in Q1? — **No (recommendation / working conclusion)**

With AMS + web + 3 already locked, a **second brick-and-mortar in Q1 is not worthwhile** in this scenario.

| Factor | Why a 2nd Q1 store hurts more than it helps |
|--------|-----------------------------------------------|
| Sim guidance | Explicit tip: open **one** store for test marketing; learn before expanding |
| Team cadence | Goal was **1 new city/quarter → all four by Q4**; two in Q1 breaks that discipline without necessity |
| Learning | Both stores would open the same quarter (full-quarter lead time) — **no** AMS results to inform city #2 |
| Capacity | 3 printers = **1,560/qtr**; early demand << potential; web already adds a second demand surface — capacity is for depth, not a second physical footprint yet |
| Cash | AMS+web+3 ≈ **$1,006k** outlay → ~**$494k** left. NYC #2 ($200k) → ~**$294k** (**breaches $300k floor**). Rio ($90k) or Bangalore ($84k) keep the floor but leave little buffer for surprises |
| Leases | Already **$104k/qtr** (AMS $44k + web $60k); a 2nd store adds $13k–$62k/qtr before you’ve proven Mountain/service |
| Strategy | Mountain beachhead in Amsterdam + global web is the sidestep; a 2nd store is expansion, not focus |
| Cannibalization | Store↔web already cannibalizes; a 2nd store adds complexity without test data |

**Open city #2 in Q2** after Q2 results (demand, judgment, cash, classmate moves). Prefer order debate then among NYC / Rio / Bangalore.

## Capacity: why 3 not 2

External/Q1 proven-approaches style guidance used a **~16–24 units/day** early band:

| Printers | Units/day | Units/quarter | Reading |
|---------:|----------:|--------------:|---------|
| 2 | 16 | 1,040 | Bottom of band — cautious, not “extra” with web on |
| **3** | **24** | **1,560** | **Top of band — matches “extra capacity” + dual channel** |

**AMS + web + 2** meets the *minimum* of that band.  
**AMS + web + 3** is the better call if dual-channel + extra headroom is the intent.

Plant remains **Bangalore** (sim-fixed). Airfreight to Amsterdam is a real cost (firm pays shipping).

**Amsterdam + Rec-as-true-primary** conflicts with sidestep/high-WTP emphasis → knife-fight risk.
