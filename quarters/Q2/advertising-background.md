## Philosophy

Assuming the right benefits are selected and prioritized, the agency can create effective ads — but it **starts with the message you conceive**.

## What you decide each ad (Workspace)

1. **Name the ad** — convey the message or brand you want to promote.
2. **Select benefits** from the menus — items the target market finds persuasive. Do **not** choose too many (clutter). Experiment for optimum; **maximum = 9**.
3. **Rank benefits high → low** — #1 is most visible; lower ranks appear smaller.
4. **Indicate which brand** the ad emphasizes. If none, the ad promotes the **company as a whole**.
5. **Preview** as print ad **and** web page (same content, different formatting). Optionally create **different ads per medium**.

Note: there is a **cost to design or modify** an ad (confirm current $ in Workspace).

## Decision tip (test market)

- Design **at least two ads** for the test market — experiment to see what customers respond to.
- Typical split: **primary segment** + **secondary segment**; optional **third** corporate/company ad.
- Multiple ads reduce risk and maximize learning in Q2.

External heuristic (advisory): strong teams often use ~**5–6** attributes (brand name → motivator → key features), not the full 9.

## Truth-in-advertising vs Hike Bike build

Ad claims must match the bike (Brand Judgment + Ad Judgment). Hike Bike currently has:

| Spec | Implication for ads |
|------|---------------------|
| Rugged frame · mountain tires · 24-speed · front suspension | Steep trail / adventure / tough carbon / high tread / gears = **on-message** |
| **No lights · no reflectors** | Do **not** pick “lights” or “reflectors everywhere” |
| Polymer gel **all-purpose** seat (not comfort seat) | Avoid “comfort seat” claim |
| Basic straight bars (not labeled comfort bars) | Prefer not to lead with “comfort straight handlebar” |
| Standard carbon (not elite materials) | Soft-pedal “elite look”; 3D / adventure / tough OK |
| Parts ~$337; COGS volume-dependent | “Great price” / rebate only if pricing strategy supports it |
